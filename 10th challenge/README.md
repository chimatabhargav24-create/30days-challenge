1. Start the program.
2. Declare arrays for temperature, humidity, and AQI.
3. Display the menu with 7 options.
4. Ask the user to enter their choice.
5. If choice is 1, enter and store 7 days of environmental data for all 5 zones.
6. If choice is 2, display all entered data.
7. If choice is 3, calculate and display the average temperature, humidity, and AQI.
8. If choice is 4, detect and count risk days for each zone.
9. If choice is 5, calculate the Green Index and display zone rankings.
10. If choice is 6, display environmental recommendations.
11. If choice is 7, display the thank-you message and exit.
12. If the choice is invalid, display an error message.
13. Repeat the menu until the user selects exit.
14. Stop the program
