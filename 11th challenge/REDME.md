1. Start the program.
2. Declare arrays to store water usage of 5 zones for 7 days and their daily targets.
3. Display the menu and ask the user to enter a choice.
4. If the user selects data entry, read the water usage and daily targets for all zones.
5. If the user selects display data, print the water usage of all zones in tabular form.
6. If the user selects audit report, calculate total usage, average usage, peak usage, and peak day for each zone.
7. Check the water usage for over-limit days and sudden spikes.
8. Calculate the excess water usage and the number of alert days for each zone.
9. Rank the zones based on excess water usage and display suitable water conservation actions.
10. If the user selects exit, terminate the program.
11. If the choice is invalid, display an error message.
12. Repeat the menu until the user exits.
13. Stop.
