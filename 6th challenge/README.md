### Algorithm: Pattern Detective

* Start.

* Read `N` and validate that it is between 5 and 12.

* Read `N` array elements and validate each reading is between 0 and 1000.

* Display the original array.

* Calculate the sum, average, minimum, maximum, and second-largest distinct value.

* Count the local peaks in the array.

* Find the longest strictly increasing contiguous run.

* Read `K` and rotate the array according to its sign.

* Display the rotated array.

* Read the last two registration digits `R` and calculate `D = (R % 9) + 1`.

* Count and display the readings divisible by `D`.

* Stop.
