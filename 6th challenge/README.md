Algorithm
1. Start
2. Read `N` and validate that it is between 5 and 12.
3. Read `N` array elements and validate each reading is between 0 and 1000.
4. Display the original array.
5. Calculate the sum, average, minimum, maximum, and second-largest distinct value.
6. Count the local peaks in the array.
7. Find the longest strictly increasing contiguous run.
8. Read `K` and rotate the array according to its sign.
9. Display the rotated array.
10. Read the last two registration digits `R` and calculate `D = (R % 9) + 1`.
11. Count and display the readings divisible by `D`
12. Stop
