1. Start the program.
2. Declare a 2D array of 5 rows and 8 columns.
3. Initialize all 40 seats with 0 (available).
4. Display the menu with six options.
5. Read the user's choice.
6. If the choice is 1, display all seats with their booking status.
7. If the choice is 2, enter the row and seat number, check availability, and book the seat.
8. If the choice is 3, enter the row and seat number, check whether it is booked, and cancel the booking.
9. If the choice is 4, enter the group size and search for consecutive available seats. If found, book those seats.
10. If the choice is 5, count booked and available seats and calculate the occupancy percentage.
11. Find and display the busiest row or rows.
12. If the choice is 6, display the thank-you message and exit.
13. If the user enters an invalid choice or seat number, display an error message.
14. Repeat the menu until the user selects option 6.
15. Stop the program.
